# Main reference: Limusic v1.3.0

The user specified [SimoHypers/limusic v1.3.0](https://github.com/SimoHypers/limusic/releases/tag/v1.3.0). This replaces ambiguous references to similarly named music apps.

Desktop retains the navigation rail, central browsing pane, bottom player and right-side Queue/Lyrics tabs. Phones use bottom navigation. The expanded player gives the track title and sleeve the central pane while keeping transport visible.

The original record sleeve uses token-colored grooves, a magenta center label, a stylus and diagonal bands. Limusic provides the desktop audio engine. Upcoming remote artwork, queue management and lyrics belong to the main-screens phase.

Kotlin + Compose remains the requested stack; adopting the reference does not approve a Rust/Tauri migration.
